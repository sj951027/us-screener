# patch_note/ — 패치 이력 (정본 규칙)

> 코드·워크플로·페이지의 **동작이 바뀌는 모든 변경**은 여기에 패치노트를 남긴다.
> (2026-08-22 도입 — US_PROJECT_KNOWLEDGE.md §5 결정로그와 상호 참조)

## 규칙

- 파일명: `vNN_YYYYMMDD.md` (NN = 2자리 순번, 날짜 = 적용일). 예: `v03_20260822.md`
- 한 패치노트 = 한 번의 논리적 변경(같은 날 여러 커밋이어도 주제가 같으면 하나).
- 필수 항목: **무엇을 / 왜(근거 실측·문서 링크) / 바뀐 파일 / 검증 방법 / 남은 한계**.
- 대상: 수집기·notify·워크플로·페이지(us.html 등)·스코어 로직. *제외*: research/ 산출물
  (연구 문서가 곧 기록), docs/data 자동 커밋, 오타 수정.
- 문서만 바뀐 변경(지식문서 갱신 등)은 §5 결정로그로 충분 — 패치노트 불요.
- 순번은 소급하지 않는다. 규칙 도입 전 변경 2건은 v01·v02 로 소급 기록(최초 1회 한정).
